- **[FR-1]** Дано: администратор открыл настройки OIDC. Когда: он смотрит на раздел настроек. Тогда: виден переключатель «создавать пользователя автоматически, если его нет» (по умолчанию выключен) и поле выбора роли по умолчанию.
- **[FR-2]** Дано: роль по умолчанию не выбрана. Когда: администратор пытается включить переключатель автосоздания. Тогда: включить его не получается — система требует сначала выбрать роль.
- **[FR-3]** Дано: переключатель включён, роль по умолчанию выбрана. Когда: человек впервые успешно проходит вход через OIDC, и в listmonk нет пользователя с его e-mail. Тогда: listmonk создаёт обычного, сразу активного пользователя с этим e-mail как логином, без пароля, и назначает ему выбранную роль по умолчанию.
- **[FR-4]** Дано: переключатель включён, пользователь с таким e-mail уже есть в listmonk. Когда: он входит через OIDC. Тогда: новый пользователь не создаётся, он входит под своей существующей учётной записью.
- **[FR-5]** Дано: переключатель выключен. Когда: человек, не заведённый в listmonk вручную, пытается войти через OIDC. Тогда: вход отклоняется, новый пользователь не создаётся.
