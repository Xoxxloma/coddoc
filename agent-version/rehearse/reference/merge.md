# Задание: свести вопросы трёх ролей

Исполнитель, архитектор и безопасник прочитали документ и задали вопросы. Ты оставляешь только критичные и сводишь их в
один список. Аналитик прочтёт его до того, как отдать документ в разработку, и ответит текстом.

## Два правила

1. **Нового не добавляешь:** ни вопросов, ни опор. Опоры переносишь из блоков ролей дословно, с путём и строкой.
2. **Ничего не правишь и не создаёшь файлов.**

## Что читать

`Документ` — целиком. `Документ сверху` — целиком, если дан. Больше ничего.

## Что выбросить

Пройди по каждому вопросу каждой роли. Выброси вопрос, если верно хоть одно:

1. Документ на него отвечает: есть строка, где ответ написан прямо. Ответ может стоять не там, где опора: прежде чем
   оставить вопрос, найди его предмет по всему документу ключевыми словами (`Grep`).
2. Он о том, чего документ не описывает по замыслу: персональные данные и сроки их хранения, журналы и метрики,
   негативные тесты, разбивка списка на страницы, числа нагрузки, которых в документе нет, проверка после выката.
3. Он требует описать чужой сервис: его адреса, поля, коды, поведение, права и настройки. Что делает наша сторона,
   когда сосед отказал, промолчал или ответил дважды, — не чужой контракт, такой вопрос остаётся.
4. Документ объявил это неизменным и сам этого не меняет.
5. Он не критичный: ты не можешь назвать, что сломается, если исполнитель решит сам, — потеряются или задвоятся
   данные, действие пройдёт без права, человек увидит не то, придётся переделывать после выката.

## Что свести

- Два вопроса сливай в один пункт, только если ответ на один закрывает и другой. Роли — обе, опоры — не больше двух.
  Не закрывает — два пункта, даже про один объект.
- Текст пункта — вопрос одной из ролей. Меняешь его, только когда сводишь два вопроса в один или когда в нём есть имя
  поля, адреса, кода или число, которых нет ни в `Документе`, ни в `Документе сверху`: такое слово перескажи смыслом.
- Первым — пункт, неверное решение по которому дороже всего исправить после выката.
- Не больше десяти. Осталось больше — оставь самые дорогие.

## Ответ

Только эти два блока, без текста до и после:

```
## СПИСОК
1. <вопрос>
   чем грозит: <одна фраза: что сломается, если исполнитель решит неверно>
   роли: <исполнитель, архитектор, безопасник — те, кто спросил>
   опора: <путь>:<строка> — «<кусок>»
```

- Две опоры — две строки `опора:`.
- Ни одного вопроса не осталось — блок из одной строки `## СПИСОК`.

Под списком — блок `## СНЯТО`: каждый выброшенный вопрос одной строкой.

```
## СНЯТО
- <роль>, <вопрос в 5–10 словах> — <ответ есть: <путь>:<строка> | вне предмета | чужой контракт | неизменное | не критично | в пункте <N>>
```
