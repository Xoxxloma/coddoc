# Слежка за планом

Повтор — инструментами CronCreate, CronList, CronDelete. Задача слежки — повторяющаяся, с промптом
`/work-plan <имя плана>`. Есть ли она — смотри только через CronList, не по памяти разговора.

## «следи»

1. План — выбранный по правилам Шага 2. Планов нет или выбран «новый план» — создай по Шагу 3 и следи за каждым
   созданным, дальше с п.3.
2. CronList: задача с промптом `/work-plan <имя>` есть — ответь «Уже слежу за планом <имя>. Остановить —
   /work-plan стоп» и остановись. Нет — обнови план по Шагу 4; «без изменений» там — одна строка, и дальше п.3.
3. Расписание — строки `слежка:` и `расписание:` файла `<корень>/.coddoc-tmp/coddoc-settings/work-plan.md`, по
   этому пути, без поиска. Файла нет — «каждые 10 минут», `*/10 * * * *`.
4. CronCreate: расписание как есть, промпт `/work-plan <имя>`, повторяющаяся. Файл есть, а строки `расписание:` в
   нём нет, или CronCreate её отверг — `*/10 * * * *` и в отчёт строку «Расписание в настройках не читается — поправь:
   /coddoc-settings».
5. После отчёта плана — строка: «Слежу за планом <имя> <слежка>, пока открыта эта сессия; после перезапуска — снова
   /work-plan следи. Остановить — /work-plan стоп».

## «стоп»

CronList, затем CronDelete каждой задачи с промптом `/work-plan …`; в аргументе имя плана — только задачи с промптом
`/work-plan <имя>`. Ответ — «Слежка за планом <имя> снята» по каждой снятой; таких задач нет — «Слежки нет».
