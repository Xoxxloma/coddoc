# Слежка за планом работы

Как часто `/work-plan следи` обновляет план. Файл — `.coddoc-tmp/coddoc-settings/work-plan.md`, пишет его только
скрипт `settings.py` (тот же, что в SKILL.md). Файла нет — каждые 10 минут.

1. **Интервал** — из слов человека, один из: `5m`, `10m`, `15m`, `20m`, `30m` (минуты), `1h`, `2h` (часы). Назван
   другой («раз в 7 минут», «раз в 3 часа») — предложи ближайший из списка и спроси. Не назван — `show`, покажи
   строку «слежка за планом» и спроси, как часто.
2. **Сначала `--dry-run`:** `settings.py watch --every <интервал> --dry-run` — покажи итоговый файл и спроси
   «записать?». После «да» — та же команда без `--dry-run`.
3. **Ответ** — по последней строке:
   - `ok` — «Записано: <строка «слежка» из файла>. Действует со следующего `/work-plan следи`; если слежка уже идёт —
     `/work-plan стоп` и снова `/work-plan следи`».
   - `error every` — интервал не из списка: строку над ней передай как есть и спроси снова.
   - `error bad-file` (при `show` или `check`) — файл поправлен руками: предложи записать заново шагом 2.
