# Документы задачи из любой ветки

Скрипт `peek.py` лежит в папке `reference/` рядом с этим файлом. Он смотрит `coddoc/` во всех локальных ветках и в
origin, не переключая ветку: текущая ветка, индекс и рабочая копия не меняются. Твоя работа — запустить одну команду
и пересказать вывод.

## Порядок

1. **Что передать.** Ключ задачи (`PAY-123`) — как есть. Просят найти по словам — слова как есть: скрипт ищет
   строки, где есть все слова, без учёта регистра. Не названо ни то, ни другое — спроси одной строкой.

2. **Команда** — из папки репозитория, одна. Python — `python3`, на Windows — `python`:

   ```
   python3 .gigacode/skills/peek/reference/peek.py "<ключ или слова>"
   ```

   Если скиллы установлены в другую папку, путь до `reference/` начинается с неё.

3. **Ответ** — по последней строке вывода, она начинается с `peek:`.
   - `peek: ok …` — строки над ней как есть: ключ и путь, ветка · автор · дата, «ещё в», файлы со статусом. В конце —
     «Открыть в браузере: /to-html <путь из `path=`>».
   - `peek: found N`, N > 0 — найденные строки как есть; в конце — «Документы задачи: /peek <ключ>».
   - `peek: found 0` — не нашлось; предложи другие слова.
   - Есть строка «origin не обновлён» — передай её: показано то, что было в репозитории до этого.
   - `peek: error <код>` или скрипт не запустился — подсказка из таблицы, больше ничего.

   Спросили о содержании документа — читай файлы из папки выгрузки (`path=`).

| В выводе | Подсказка пользователю |
|---|---|
| `peek: error usage` | Нужен ключ задачи или слова. |
| `peek: error not-repo` | Запусти из папки репозитория с документами. |
| `peek: error no-coddoc` | Ни в одной ветке нет `coddoc/` — это не репозиторий с документами задач. |
| `peek: error not-found` | Такого ключа нет ни в одной ветке — проверь ключ. |
| `peek: error no-write` | В `.coddoc-tmp/` нельзя писать. |
| `peek: error no-git` | Нужен установленный git. |
| `command not found`, `is not recognized`, `не является … командой` | Нужен Python 3: на Windows — команда `python`, на macOS и Linux — `python3`. |

## Чего не делать

- Не переключать ветку, не делать `checkout`, `stash`, `pull`, `worktree` — скрипт обходится без них.
- Не искать документы задачи сам по веткам и `coddoc/` — это делает скрипт.
- Не править файлы в `.coddoc-tmp/peek/` — это копия, следующий вызов её перезапишет.
