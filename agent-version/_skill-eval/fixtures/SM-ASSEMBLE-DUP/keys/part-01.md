## Публичный контракт

### `GET /api/nights/:id`
Ночь наблюдений по идентификатору.
- `id` (path, uuid) — ночь

### `GET /api/observers/{ids}`
Наблюдатели по списку идентификаторов.
- `ids` (path, список uuid через запятую)

### `DELETE /api/domes/{id}`
Снять купол с обслуживания.
- `id` (path, uuid) — купол

### `DELETE /api/domes/:id`
Снять купол с обслуживания (маршрут из роутера).
- только дежурный оператор

### `GET /files/{upload.s3.public_url}`
Публичная ссылка на снимок — путь из конфига.
- отдаёт файл из хранилища
