# Фикстура TS-OPEN — открытые пункты, о которых аналитика не спрашивали (`technical-spec-doc`)

Заведена 2026-11-25 под спеку 2.5.1: «ожидаемая нагрузка» снята с гейта 8 и подсказки §5.1; в реестре — строка
«Открытым в файл уйдёт». Повод — прод: спека записала ⚠️ нагрузки и ⚠️/🟡 по схеме событий внешней системы, не
спросив аналитика (2 из 2 прод-логов одной задачи).

Один ход, «ПРОДОЛЖЕНИЕ»: БТ `FLT-905` (карта машин подрядчиков), положения приходят событиями Kafka из новой
внешней системы «ТрансЛинк», которой в карточках нет. Ответы аналитика закрывают все гейты; о схеме событий
(топик, поля) и о нагрузке не сказано ничего. Среда — карточки `fleet-*` из `OCC-NEW`.

**Новая версия, верно:** реестр со строкой «Открытым в файл уйдёт» и в ней ❓ по схеме событий; ход кончается
вопросом про схему; файла нет. Или файл, где пункт о схеме отложен словами аналитика (в этой пробе их нет).
**Красное:** ⚠️/TBD про нагрузку в файле; открытый пункт в файле, о котором не спрашивали (схема, доступ).
**База:** ожидаем файл с такими пунктами. Грейдер — `grade-ts-open.mjs`, проба `ts-open`.

**С 2.5.2 (`ts-open-hd`, ход 2 — `hd-turn2.txt`):** строка реестра «Открытым в файл уйдёт» снята (5.138). Верно — в ходе 1
вопрос о стыке «ТрансЛинк» с открытыми сторонами: адрес/топик, поля, доступ. Грейдер — `grade-hd.mjs --sys=ТрансЛинк
--need=адрес,поля,доступ`. База 2.5.0 по этой метрике — 0 из 3 (доступ не спрошен ни разу).

**С 2.6.0 (правка ядра, `ts-open`):** верно — в ходе 1 сводки новых карточек (путь, поля) с «годится?», файла нет.
Грейдер — `grade-shown.mjs` (счётчики показанного; вердикта по одному ходу нет). База — содержимое карточки в ходе 1: 1 из 12.
