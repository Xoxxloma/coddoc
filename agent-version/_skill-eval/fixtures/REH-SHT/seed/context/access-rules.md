# Доступ и журналы во внутренних системах

## Вызовы между системами

- Система ходит в чужую систему только под сервисной учётной записью. Учётку заводит команда-владелец чужой системы
  по заявке.
- Права сервисной учётки — только на чтение того, что нужно задаче.

## Журналы

- В журнал приложения можно писать доменный логин сотрудника.
- ФИО, номер пропуска и телефон в журнал приложения не пишутся.
- Отказ в действии пишется в журнал с логином и причиной отказа.

## Данные сотрудников

- Данные из чужой системы не копируются в свою базу без согласования с командой-владельцем.
