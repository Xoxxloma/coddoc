# Фикстура REH-SHT — репетиция встречи (`rehearse`)

Заведена 2026-11-03 под `PLAN-REHEARSE.md`, срез С3. Документы — замороженные: БТ `SHT-410` из `TS-BLUE`, спека
`SHT-410` из `SR-BLUE` (выход `technical-spec-doc` 1.7.0), карточки `services/` из `TS-BLUE`. `context/access-rules.md`
написан для этой фикстуры: правила журналов и вызовов между системами — опора для безопасника.

Предмет — корпоративный шаттл и проверка пропуска: пример в `rehearse/reference/brief.md` про врача и анализы, на
медицинском документе вопрос по документу не отличить от списанного с примера.

## Пробы

| Проба | Документ, роль | Двойник | Что проверяем сверх общего |
|---|---|---|---|
| `reh-arch` | спека, архитектор | `twin-arch.md` | ловушка: служба пропусков «шлёт события» или «знает офис» — в карточке этого нет; справочник `org-directory` без карточки |
| `reh-sec` | спека, безопасник | `twin-sec.md` | опора из `context/access-rules.md`; ловушка: служба пропусков «отдаёт ФИО»; уклончивый ответ, после уточнения — по существу |
| `reh-cust` | БТ, заказчик | `twin-cust.md` | документ без карточек в вопросах; уклончивый ответ, после уточнения — по существу |
| `reh-stop` | спека, архитектор | `twin-stop.md` | на третьем вопросе «Хватит, давай итог» — следующим ходом итог, «задано 3 из N» |

## Как двойник отвечает

Промпт — `twin-rehearse.md`: ответ — текст одного раздела карточки дословно, первого подходящего сверху. `grade-reh.mjs`
раскладывает ответ по фразам карточки:

| Фраза карточки | Группа итога |
|---|---|
| «Это есть в …», «Нет, …» (посылка неверна) | снято |
| «Не знаю…» | решить до встречи |
| «как-нибудь решим», «мелочь, разберёмся», «как-нибудь разберутся» | уклончивый → ждём уточнение; группа — по ответу на уточнение, снова уклончиво → решить до встречи |
| остальное | вписать в документ |
| ответ не одной фразой (две фразы разных групп, своя приписка, самопоправка) | шум — любая группа |

Двойник на `claude-sonnet-5-5` и со строгим промптом иногда отвечает не на заданный вопрос (раздел подошёл «по словам»).
Скилл тогда законно уточняет или кладёт пункт в «решить до встречи» — такие красные читать глазами.

## Общее для всех проб

- субагент запущен; ведущий документ целиком не читал (`Read` документа без `limit` или с `limit` > 10);
- файлов не записано, вызовов за пределы песочницы нет;
- вопросов от 5 до 7, по одному на сообщение;
- каждая показанная опора есть в файле (строка ±2) — то есть ведущий сверку сделал;
- показанный вопрос дословно есть в ответе субагента;
- итог есть, числа групп сходятся с ответами двойника.

Вопросы про чужой сервис с признаками ловушки грейдер печатает списком — читать глазами: вопрос «есть ли у службы
пропусков события?» законен, утверждение «служба присылает события» — выдумка.
