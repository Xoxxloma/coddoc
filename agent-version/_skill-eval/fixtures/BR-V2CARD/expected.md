## Ограничения — ровно два

| | Р1 — включает роль | Р2 — включает сосед |
|---|---|---|
| Имя | участок в архиве: замеры на него не принимаются | переключатель доступа к API журнала у `land-registry`: включённый флаг — любая ручка отказывает |
| Кто управляет | `владелец участка` (агроном — владелец своего участка) | `land-registry`, сосед из `manifest.yaml` |
| Что выключает | внесение замеров на этот участок; участок пропадает из списка своих | весь API сервиса, вместе с внесением замеров; ошибка «Интеграция с журналом замеров отключена» |
| Где записано (место v2) | «Роли и доступ», строка `владелец участка`, «Что может» — :334 | «Зависит от», строка `land-registry`, «Зачем» — :317 |
| Где ещё видно | «Что умеет» :40; `POST /api/v1/ledger/entries` :106 (`403` — участок в архиве); `GET /api/v1/ledger/plots` :156; `DELETE /api/v1/ledger/plots/{id}` :161–165; `Plot` :299–300 | нигде |

Дословно:

- :334 — `| владелец участка | менять участок и убирать в архив; замеры принимаются только на свои неархивные участки |`
- :317 — `| \`land-registry\` | срезы дашбордов агрослужбы, отчёты дочерних хозяйств и справочники регионов и хозяйств для
  подстановки наименований; плюс переключатель доступа к API журнала замеров — включённый флаг означает запрет: любая ручка
  отвечает ошибкой «Интеграция с журналом замеров отключена» |`

### Якоря для П-а

Сначала ищем якорь, потом читаем абзац: засчитывается только гипотеза о текущем поведении (см. README, «Как грейдить»).

- **Р1:** корень `архив` (архив, архивн-, в архиве). После выкидки блоков в карточке он встречается только применительно
  к участку. Подкрепление — `владел` + `участ`, «неархивн».
- **Р2:** `land-registry`, или «земельн… реестр», или «реестр» + одно из: `флаг`, `переключат`, `отключ`, `запрет`,
  «Интеграция с журналом замеров отключена». Одно «land-registry» без флага не засчитывается: сосед назван ещё и как
  справочник регионов и хозяйств.

Примеры зелёного (формулировки не обязательны):

- «Сейчас владелец может убрать участок в архив, и замеры на него не принимаются — в новых списках “нет замера” архивные
  участки не показываем, верно?»
- «По карточке весь журнал отключается флагом доступа у земельного реестра (`land-registry`) — при включённом флаге
  внесение замеров недоступно целиком; так и остаётся?»

## Обычные ролевые права — по «Что может» (:330–335)

Это не ограничения. В вопросе о ролях (гейт 3) они законны. Гипотеза риска в гейте 6 с одним из них в предмете — лишняя
(П-в).

| Роль | Права | Якоря |
|---|---|---|
| `AGRONOMIST` :330 | вносить свои замеры; удалять свои замеры; отправлять свои замеры; запрашивать окно правки; отзывать окно правки; вести свои участки | `свои замер`, `удал`, `отправ`, `окн`, `свои участ` |
| `HEAD_AGRONOMIST` :331 | подтверждать недели; возвращать недели; решать по окнам правки; вести шаблоны и назначения; просить передачу шаблонов; смотреть сводки; смотреть недельную сводку; оговорка «принадлежность агронома не проверяется» | `подтвержд`, `возвра`, `окн`, `шаблон`, `сводк`, `принадлежн`, «любого агронома» |
| `METHODIST` :332 | вести справочник культур и групп; решать по передаче шаблонов; смотреть сводки; смотреть замеры агрономов; смотреть все шаблоны | `справочник`, `культур`, `передач`, `сводк`, `шаблон` |
| автор шаблона :333 | менять шаблон и его назначения; удалять и смотреть шаблон может любой главный агроном | `автор шаблона`, `шаблон` |
| владелец участка :334 | менять участок (обычное право); «убирать в архив» — это **Р1**, не обычное право | `менять участ` |

Итого 20 обычных прав (6 + 7 + 5 + 1 + 1) и одна оговорка. Якоря грубые: найденное место сверять с предметом гипотезы.

## П-б — `вход`

- :336 — строка `вход`: как сервис узнаёт пользователя (заголовки `X-Employee-Number` и `X-Employee-Roles`, без номера
  `401`). Это не роль.
- :335 — `без входа`: «нет: запрос без заголовка номера сотрудника получает `401`». П-б её не меряет.
- Красное: пункт «вход» или `` `вход` `` в перечне ролей вопроса о ролях, в списке ролей гипотез, в §5.3 записанного
  файла. Не красное: слово «вход» в описании («сотрудник входит по заголовку»).

## Не ограничения — похоже, но не считается

| Что | Где | Почему не ограничение |
|---|---|---|
| окно правки прошедшей недели | :22, :48, :106 (`423`), `WeekWindow` | запрет ставит время, роль его снимает, а не включает; это обычное право `HEAD_AGRONOMIST` «решать по окнам правки» |
| откат записи при сбое брокера и `audit-hub` | :223 | сбой, а не переключатель: условием никто не управляет |
| удаление дня только в черновике, возврат только с комментарием, один шаблон на агронома | :24, :28, :37 | правила состояния и формы, никем не включаются |
| сроки из настроек (`ledger.drafts.retention-days`, `ledger.windows.open-hours`) | :230, :249 | параметр срока, отказа не даёт |
| выгрузка в PDF «пока недоступна» | :31 | не реализована, переключателя нет |
| автоотправка недели в понедельник | :25, `UnsubmittedWeeksJob` | расписание, не запрет |

## Красное — отдельными счётчиками

1. **Р1 НЕ ПРЕДЪЯВЛЕНА** — архива участка нет ни в одной гипотезе первого хода.
2. **Р2 НЕ ПРЕДЪЯВЛЕНА** — переключателя у `land-registry` нет ни в одной гипотезе первого хода (главный сигнал: Р2 есть
   только в «Зачем»).
3. **ОГРАНИЧЕНИЕ ФАКТОМ, БЕЗ ГИПОТЕЗЫ** — названо в «как сейчас» утверждением и на подтверждение не вынесено.
4. **`ВХОД` РОЛЬЮ** — П-б.
5. **ЛИШНЯЯ ГИПОТЕЗА РИСКА** — обычное право из таблицы выше в гейте 6; каждую считать.
6. **ЗАПРЕТ ВЫДУМАН** — гипотеза об ограничении, которого в карточке нет (например, «методист может закрыть приём
   замеров»). Не входит в пороги, но записывается.
