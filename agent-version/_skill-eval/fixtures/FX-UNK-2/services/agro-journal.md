Журнал агронома тепличного комбината: теплицы и записи обходов. Ведёт команда «Журнал агронома».

## Назначение

Рабочий журнал агрономов комбината. Агроном открывает теплицу, видит культуру, дату последнего
графика полива и записи обходов, после обхода оставляет свою запись. Главные объекты — теплицы и
записи обходов.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть список теплиц и карточку теплицы | Агроном, главный агроном |
| Оставить запись обхода по теплице | Агроном, главный агроном |
| Отправить теплицу в архив и вернуть из архива | Главный агроном |

## Бизнес-правила

### `Greenhouse` — теплица
- в работе (`archived: false`) — видна в списке, по ней оставляют записи обходов
- в архиве (`archived: true`) — главный агроном; в списке не видна, записи обходов сохраняются

## Публичный контракт

### `GET /v1/greenhouses`
Список теплиц.
сущности: → `Greenhouse`, без архивных
- весь список одним ответом, без пагинации

### `GET /v1/greenhouses/{id}`
Теплица по идентификатору.
сущности: → `Greenhouse`

### `GET /v1/greenhouses/{id}/notes`
Записи обходов теплицы, новые сверху.
сущности: → `InspectionNote`
- пагинация `page`, `size`; ответ `items`, `page`, `size`, `total`

### `POST /v1/greenhouses/{id}/archive`
Отправить теплицу в архив.
сущности: → `Greenhouse`
- `403` — не главный агроном

### `POST /v1/greenhouses/{id}/notes`
Запись обхода.
сущности: ← `text` · → `InspectionNote`
- `400 VALIDATION_FAILED` — пустой текст; в теле `fields`

### `POST /v1/greenhouses/{id}/restore`
Вернуть теплицу из архива.
сущности: → `Greenhouse`
- `403` — не главный агроном

## События

### потребляет `irrigation.schedule.changed`
Система полива поменяла график теплицы — обновляем дату графика в карточке теплицы.
- группа `agro-journal`, offset коммитится после записи в БД
- из тела читаются номер теплицы и дата графика; остальное не используется
- повтор безопасен: дата записывается поверх прежней

## Владеет данными

### `Greenhouse`
Теплица комбината.
- `id`: `string`
- `number`: `int` — номер теплицы на комбинате
- `crop`: `string` — культура
- `irrigationScheduleDate`: `date?` — дата последнего графика полива; `null`, пока график не приходил
- `archived`: `boolean`

### `InspectionNote`
Запись обхода теплицы.
- `id`: `string`
- `greenhouseId`: `string`
- `authorLogin`: `string` — доменный логин из входа
- `text`: `string`
- `createdAt`: `timestamp`
