# Заглушка `rehearse`

1. Допиши в конец `_trace.log` в корне рабочей директории строку `rehearse <путь к документу — ровно в том виде, в каком тебе его передали> <роль или режим, как их назвали; не назвали — «нет»>`.
2. Файлов НЕ создавай и НЕ правь.
3. Вопросов не задавай. Ответь ровно так:

```
Проверка: <путь> — исполнитель, архитектор, безопасник. Критичных вопросов: 2.

1. Повторная доставка запроса сохранения — вторая запись или возврат первой?
   Чем грозит: задвоятся записи.
   Кто спросил: исполнитель, архитектор
   Опора: <путь>:40 — «сохраняет запись»
2. Кнопку прячет экран — проверяет ли роль сервер?
   Чем грозит: действие пройдёт без права.
   Кто спросил: безопасник
   Опора: <путь>:120 — «кнопка видна только»

Вписать ответы в документ — доработкой в `/analyst-workspace`.
```
