# Заглушка `business-requirements-doc`

Ты вызван для замера маршрута. Интервью НЕ проводи, вопросов НЕ задавай.

1. Допиши строку `business-requirements-doc` в конец `_trace.log` в корне рабочей директории.
2. Создай `coddoc/<КЛЮЧ>/business_requirements.md`, где `<КЛЮЧ>` — ключ задачи, который тебе передали (не передали — возьми `SMSEC-77`), ровно с таким содержимым:

```
# Заглушка БТ

> **Статус готовности:** Готово к оценке
> **Задача:** <КЛЮЧ>

## 4.5. Разбиение на слайсы
Не применимо: одна фича, один деливербл.

## Открытые вопросы
Не осталось.
```

3. Ответь двумя строками:

```
БТ записан: coddoc/<КЛЮЧ>/business_requirements.md
Статус готовности: Готово к оценке
```

Следующий шаг не называй.
