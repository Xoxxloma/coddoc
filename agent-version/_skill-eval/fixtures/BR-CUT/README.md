# Фикстура BR-CUT — БТ с несколькими частями (`business-requirements-doc`)

Заведена 2026-10-06 под замену терминов: «слайс» → «часть», «деливербл» → «поставка», английские
дубли заголовков убраны (5.35). До неё пробы «БТ режется на части → таблица §4.5 и вопрос в
ответе» на текущем стенде не было: бриф `BS-1` (`_skill-eval/fixtures/bs1-prompt.txt` в корне
репы) в раннер не подключён. Ответ аналитика взят из него, ключ и форма — под нынешние гейты.

Одноходовая, «ПРОДОЛЖЕНИЕ»: все гейты закрыты, срок отложен явным «пропускаем». Аналитик сам
подсказывает схлопывание — «все три элемента опираются на одни и те же данные».

**Верно:** файл `coddoc/ARS-180/business_requirements.md` этим ходом; §4.5 «Разбиение на части» —
таблица из ≥2 частей, каждое FR ровно в одной; ответ несёт строки «Разбиение:» и «Предлагаю:» с
именами частей, строку «Открытые пункты» (срок) и кончается вопросом; ни в файле, ни в ответе
нет «слайс», «деливербл», slice, deliverable; заголовки без английских скобок.

Окружение пустое. Грейдер — `grade-terms.mjs --case=cut`, проба `br-cut`.
