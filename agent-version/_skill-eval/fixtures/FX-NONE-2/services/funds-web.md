Рабочее место хранителя. Ведёт команда «Учёт фондов».

## Назначение

Веб-интерфейс, в котором хранители и главный хранитель работают с учётом фондов: находят предмет,
открывают и правят его карточку, ставят новые предметы на учёт и ведут справочник мест хранения.
Главные объекты — предметы и места хранения.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Найти предмет по инвентарному номеру, названию или месту хранения | Хранитель |
| Открыть карточку предмета и изменить её — кнопки «Изменить» нет у предметов в чужих местах | Хранитель |
| Сменить место хранения предмета — выпадающим списком в форме правки карточки | Хранитель |
| Поставить предмет на учёт | Главный хранитель |
| Вести справочник мест хранения | Главный хранитель |
| Видеть в меню только разделы своей роли | Все роли |

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/items` | Предметы | ищет по номеру, названию, месту хранения; открывает карточку |
| `/items/:id` | Карточка предмета | смотрит описание, сохранность и место хранения |
| `/items/:id/edit` | Правка карточки | меняет поля карточки, включая место хранения |
| `/items/new` | Постановка на учёт | заводит предмет с инвентарным номером и местом хранения |
| `/locations` | Места хранения | заводит место, меняет ответственного хранителя, отключает место |
| `/login` | Вход | вводит логин и пароль учёта фондов |

## Потребляемые API
| Сервис | Вызов | Зачем |
|---|---|---|
| `funds-registry` | `GET /v1/items` | поиск предметов — `/items` |
| `funds-registry` | `GET /v1/items/{id}` | карточка предмета — `/items/:id`, `/items/:id/edit` |
| `funds-registry` | `GET /v1/locations` | список мест — фильтр в `/items`, форма правки, `/locations` |
| `funds-registry` | `GET /v1/me` | кто вошёл и его роль — меню и кнопки |
| `funds-registry` | `PATCH /v1/items/{id}` | сохранение карточки — `/items/:id/edit` |
| `funds-registry` | `PATCH /v1/locations/{id}` | правка места — `/locations` |
| `funds-registry` | `POST /v1/items` | постановка на учёт — `/items/new` |
| `funds-registry` | `POST /v1/locations` | новое место — `/locations` |
