Релизы — по средам, в санитарный день музея.

## Назначение

Сервис, в котором музей ведёт учёт своих фондов: каждый предмет стоит на учёте с инвентарным
номером, описанием, сохранностью и местом хранения, а у каждого места хранения есть ответственный
хранитель. Поддерживает постановку предмета на учёт, правку карточки предмета, поиск предметов,
ведение справочника мест хранения. Главные объекты — музейные предметы и места хранения.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Найти предмет по инвентарному номеру, названию или месту хранения | Хранитель |
| Открыть карточку предмета | Хранитель |
| Изменить карточку предмета, включая место хранения, — только у предметов в своих местах | Хранитель |
| Поставить предмет на учёт | Главный хранитель |
| Завести место хранения и назначить ответственного хранителя | Главный хранитель |
| Разрешить или запретить публикацию предмета | Главный хранитель |

## Бизнес-правила

### `Item` — музейный предмет
- ставится на учёт главным хранителем; инвентарный номер уникален и после постановки не меняется
- карточку правит хранитель, ответственный за место, где предмет лежит сейчас, и главный хранитель
- место хранения (`locationId`) меняется той же правкой карточки, без участия хранителя нового места
- сохранность (`condition`) — `good` \| `satisfactory` \| `poor`

### `StorageLocation` — место хранения
- хранилище (`storage`) или зал (`hall`); у места ровно один ответственный хранитель
- отключённое место (`active = false`) нельзя выбрать в карточке предмета; предметы в нём остаются

## Публичный контракт

### `GET /v1/items`
Поиск предметов.
сущности: → `Item`
- параметры `inventoryNumber`, `name`, `locationId`; пагинация `page`, `size`; ответ `items`, `page`, `size`, `total`

### `GET /v1/items/{id}`
Карточка предмета.
сущности: → `Item`
- `404 NOT_FOUND` — предмета нет

### `GET /v1/items/{id}/label`
Этикетка предмета для выставки.
сущности: → не сущность, ответ: `inventoryNumber`, `name`, `author`, `dating`
- доступ по сервисному токену

### `GET /v1/items/{id}/passport`
Паспорт предмета для реставратора.
сущности: → не сущность, ответ: `inventoryNumber`, `name`, `material`, `technique`, `dimensions`, `condition`
- доступ по сервисному токену

### `GET /v1/locations`
Справочник мест хранения.
сущности: → `StorageLocation`
- параметр `active`; весь справочник одним списком, без пагинации

### `GET /v1/me`
Текущий пользователь.
сущности: → `User`

### `GET /v1/published-items`
Предметы, разрешённые к публикации.
сущности: → не сущность, ответ: `inventoryNumber`, `name`, `description`, `dating`, `imageUrl`
- только `publishAllowed = true`; пагинация `page`, `size`
- доступ по сервисному токену

### `PATCH /v1/items/{id}`
Правка карточки предмета.
сущности: ← `name`, `description`, `author`, `dating`, `material`, `technique`, `dimensions`, `condition`, `locationId`, `publishAllowed` · → `Item`
- `400 VALIDATION_FAILED` — пустое название, неизвестное или отключённое место; в теле `fields`
- `403 FORBIDDEN` — хранитель не отвечает за место, где лежит предмет; `publishAllowed` меняет только главный хранитель

### `PATCH /v1/locations/{id}`
Правка места хранения.
сущности: ← `name`, `keeperLogin`, `active` · → `StorageLocation`

### `POST /v1/items`
Постановка предмета на учёт.
сущности: ← `inventoryNumber`, `name`, `locationId` и остальные поля карточки · → `Item`
- `409 INVENTORY_NUMBER_TAKEN` — номер занят

### `POST /v1/locations`
Новое место хранения.
сущности: ← `name`, `kind`, `keeperLogin` · → `StorageLocation`

## Владеет данными

### `Item`
Музейный предмет на учёте.
- `id`: `uuid`
- `inventoryNumber`: `string` — уникален
- `name`: `string`
- `description`: `string?`
- `author`: `string?`
- `dating`: `string?`
- `material`: `string?`
- `technique`: `string?`
- `dimensions`: `string?`
- `condition`: `good` \| `satisfactory` \| `poor`
- `locationId`: `uuid` — текущее место хранения
- `publishAllowed`: `boolean`
- `createdAt`: `timestamp`
- `updatedAt`: `timestamp`

### `StorageLocation`
Место хранения: хранилище или зал.
- `id`: `uuid`
- `name`: `string`
- `kind`: `storage` \| `hall`
- `keeperLogin`: `string` — ответственный хранитель
- `active`: `boolean`

### `User`
Пользователь учёта фондов; вход по логину и паролю учёта.
- `login`: `string`
- `fullName`: `string`
- `role`: `KEEPER` \| `CHIEF_KEEPER`

## Роли и доступ
| Роль | Что может |
|---|---|
| `KEEPER` | искать и открывать любые предметы; править карточки предметов в местах, за которые отвечает |
| `CHIEF_KEEPER` | всё, что хранитель, по всем местам; ставить на учёт; вести справочник мест; разрешать публикацию |
