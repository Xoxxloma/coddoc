План выставок: состав, залы, сроки монтажа. Ведёт команда «Выставочные проекты».

## Назначение

Сервис, в котором кураторы планируют выставки: заводят выставку с залом и сроками, собирают её
состав из предметов фондов по инвентарным номерам и утверждают план. Главные объекты — выставки
и состав выставок.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Завести выставку: название, зал, даты монтажа, открытия и закрытия | Куратор |
| Добавить предмет в состав выставки по инвентарному номеру и указать витрину | Куратор |
| Убрать предмет из состава — только до утверждения плана | Куратор |
| Утвердить план выставки | Администратор выставок |

## Бизнес-правила

### `Exhibition` — выставка
- черновик (`draft`) — куратор собирает состав
- утверждена (`approved`, `approvedAt`) — состав больше не меняется
- закрыта (`closed`) — после даты закрытия, ночной задачей

### `ExhibitionItem` — предмет в составе выставки
- один предмет не входит в две выставки с пересекающимися сроками
- этикетка предмета подтягивается из учёта фондов при добавлении и перед утверждением

## Публичный контракт

### `DELETE /v1/exhibitions/{exhibitionId}/items/{inventoryNumber}`
Убрать предмет из состава.
- `409 EXHIBITION_APPROVED` — план уже утверждён

### `GET /v1/exhibitions`
Выставки.
сущности: → `Exhibition`
- параметры `state`, `from`, `to`

### `GET /v1/exhibitions/{exhibitionId}/items`
Состав выставки.
сущности: → `ExhibitionItem`

### `POST /v1/exhibitions`
Новая выставка.
сущности: ← `title`, `hallCode`, `mountFrom`, `opensAt`, `closesAt` · → `Exhibition`

### `POST /v1/exhibitions/{exhibitionId}/approve`
Утвердить план.
сущности: → `Exhibition`

### `POST /v1/exhibitions/{exhibitionId}/items`
Добавить предмет в состав.
сущности: ← `inventoryNumber`, `showcase` · → `ExhibitionItem`
- `409 ITEM_BUSY` — предмет занят в выставке с пересекающимися сроками

## События

### публикует `expo.exhibition.approved`
План выставки утверждён.
- `exhibitionId: uuid`, `hallCode: string`, `mountFrom: date`, `inventoryNumbers: string[]`
- шлётся после коммита

## Фоновые задачи

### closeFinishedExhibitions
Закрытие выставок после даты закрытия.
- расписание `0 3 * * *`

## Владеет данными

### `Exhibition`
Выставка.
- `exhibitionId`: `uuid`
- `title`: `string`
- `hallCode`: `string` — код зала в плане выставок
- `mountFrom`: `date`
- `opensAt`: `date`
- `closesAt`: `date`
- `state`: `draft` \| `approved` \| `closed`
- `approvedAt`: `timestamp?`

### `ExhibitionItem`
Предмет в составе выставки.
- `exhibitionId`: `uuid`
- `inventoryNumber`: `string`
- `showcase`: `string?` — витрина
- `label`: этикетка предмета — название, автор, датировка
- `addedAt`: `timestamp`
