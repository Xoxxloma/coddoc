# RT-CUTLIVE — ведущий + настоящий `business-requirements-doc`, вход с несколькими поставками

Меряется связка: вопрос о частях (гейт 18 скилла БТ) звучит под ведущим до записи файла, и ведущий на нём
останавливается. Бриф — ответы аналитика из `BR-CUT/cut-prompt.txt` (ARS-180, три поставки), поданные одним
сообщением ведущему. Под-скиллы — заглушки `RT-BUG`, поверх них живой `business-requirements-doc` (`REAL_SUBS`).

Проба `rt-cut-live`, один ход. Верно: ход кончается вопросом о частях с вариантом «одной задачей»; файла БТ нет;
`spec-review` не вызван, вопроса гейта 2Б нет. Грейдер — `grade-cut18.mjs <раунд>`.
