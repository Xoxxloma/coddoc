# Фикстура TS-GAPS-SRC — TS-GAPS + поля справочника офисов в ответах аналитика

Вариант `TS-GAPS` под правку 5.133 (§3.2 спеки таблицей; изменённая сущность — всеми полями, известными из
источника). Отличие от `TS-GAPS` — одна фраза в `spec-prompt.txt`: «Поля справочника офисов сейчас: `id` (uuid),
`name` (string, название офиса), `city` (string, город)». Источник полей изменённой сущности есть (со слов аналитика).

Законный исход §3.2: офисы — таблицей `id`, `name`, `city` + `timezone` с пометкой «новое»; полей сверх этих
четырёх нет. Остальное — как у `ts-gaps` (`fixtures/TS-GAPS/README.md`).

Проба: `ts-gaps-src`. Оценка §3.2 — `grade-ent.mjs --case=gaps-src`.
