# tasks — backend

## Публичный контракт

### `GET /tasks/:id`
сущности: → Task
- отдаёт задачу

### `GET /tasks/{id}`
сущности: → Task
- отдаёт задачу по номеру

### `GET /users/{ids}`
сущности: → User
- пачка пользователей по списку номеров

### `GET /users/{userId}`
сущности: → User
- один пользователь
