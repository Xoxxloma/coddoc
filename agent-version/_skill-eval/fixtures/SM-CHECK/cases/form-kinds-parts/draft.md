# orders — backend

## Назначение

Принимает заказы через `OrderService` и отдаёт их статус.

## Бизнес-правила

### письмо «заказ принят»
- уходит покупателю после оплаты

## Публичный контракт

### `GET /orders/{id}`
сущности: → Order
- чужой заказ — 404 — src/orders/handler.go

### `POST /orders`
- создаёт заказ
