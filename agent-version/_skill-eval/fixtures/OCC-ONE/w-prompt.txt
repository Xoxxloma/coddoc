Явный флаг от analyst-workspace: мелкая правка. Документ сверху: coddoc/EDU-940/change_request.md.
Это ПРОДОЛЖЕНИЕ интервью: вопросы по тех-гейтам уже заданы, аналитик отвечает.
Все перечисленные сведения подтверждаю своими словами. Ключ EDU-940 подтверждаю.
homework-service — наш, владелец команда «Домашние задания». Ссылку пуша несёт поле `deeplink` события `homework.check.done`:
у вердикта «на доработку» туда пойдёт `eduapp://homework/<assignmentId>` вместо `eduapp://lesson/<lessonId>`; у «зачтено» — как сейчас.
Поле остаётся обязательным, пустым не бывает. Событие читает notify-service: кладёт `deeplink` в пуш как есть, не разбирает,
правка ему не нужна. Форму сдачи задания по такой ссылке приложение ученика открывает с прошлого релиза, старые версии
приложения — тоже. Других потребителей у поля нет.
Данные и миграции не нужны: id задания у работы уже хранится. Доступ, нагрузка, кэш и ошибки не меняются.
Выкат: только homework-service, общий релиз, флагов нет; откат — предыдущая версия сервиса, пуши снова ведут на урок.
Остальные решения — явно подтверждённое содержание документа-источника.
