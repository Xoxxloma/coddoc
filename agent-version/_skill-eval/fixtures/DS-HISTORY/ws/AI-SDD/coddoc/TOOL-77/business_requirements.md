# Бизнес-требования: порядок событий по инструменту

> **Задача:** TOOL-77

## 1. Введение и контекст

### 1.1. Описание проблемы

События об одном инструменте приходят потребителям не по порядку.

## 2. Бизнес-требования (цели и ценность)

### 2.1. Бизнес-цель

События об одном инструменте обрабатываются в порядке их появления.

## 4. Функциональные требования

**FR-1.** Ключ сообщения о возврате — `toolId`: события одного инструмента попадают в одну партицию и идут по порядку.
