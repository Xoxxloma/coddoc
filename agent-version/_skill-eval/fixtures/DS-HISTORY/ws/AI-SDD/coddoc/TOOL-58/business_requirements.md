# Бизнес-требования: возврат инструмента без зависимости от брокера

> **Задача:** TOOL-58

## 1. Введение и контекст

### 1.1. Описание проблемы

Событие о возврате отправлялось внутри транзакции возврата. Когда брокер был недоступен, транзакция откатывалась, и
клиент не мог сдать инструмент на стойке.

## 2. Бизнес-требования (цели и ценность)

### 2.1. Бизнес-цель

Приём инструмента не останавливается из-за сбоя брокера.

### 2.2. Ценность для бизнеса

Меньше очередей на стойке выдачи.

## 3. Объём проекта

### 3.2. Не входит в проект

Повторная отправка событий, не дошедших до брокера.

## 4. Функциональные требования

**FR-1.** Событие о возврате отправляется только после фиксации возврата в базе.
