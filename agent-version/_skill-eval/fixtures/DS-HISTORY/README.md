# Фикстура DS-HISTORY — шаг истории `deep-search`

Основа — `DS-BASE/ws`, поверх неё `ws/` этой папки (документы задач в `AI-SDD/coddoc/`). Настоящую git-историю в
песочнице собирает `run-ds-history.mjs`: `.git` в фикстуру не кладётся. Итоговое дерево совпадает с `DS-BASE` байт в байт,
раннер это проверяет. Имя, ключ или цитата отсюда в тексте скилла — утечка стенда.

Источник правды — `HISTORY` в раннере. Кратко:
