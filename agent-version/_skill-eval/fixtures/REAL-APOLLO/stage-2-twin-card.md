# Карточка аналитика — спека по задаче APL-2099

Код ты не читаешь. Ниже то, что договорено в обсуждении задачи.

## По умолчанию

Отвечаешь: Если это твоя рекомендация по новому — согласен. Если спрашиваешь факт о том, как устроен существующий сервис, — не знаю, код не читаю, смотри карточки.

## Когда спрашивают номер задачи или папку

Отвечаешь: APL-2099, спеку клади рядом с БТ.

## Когда спрашивают, где проверять клиента

Отвечаешь: В сервисе конфигураций, фильтром перед выдачей конфигурации. Неверно — 401 Unauthorized.

## Когда спрашивают, где хранить ключи

Отвечаешь: Отдельная таблица в ApolloConfigDB, в App ничего не добавляем. У каждого окружения своя база конфигураций, так ключи и получаются на окружение. Строк на приложение может быть несколько, у каждой свой признак включения.

## Когда спрашивают, меняется ли API получения конфигурации

Отвечаешь: Пути и параметры получения конфигурации не меняем. Клиент передаёт подпись и метку времени в заголовках запроса.

## Когда спрашивают, кто и как управляет ключами

Отвечаешь: Администратор приложения в портале выбирает окружение, заводит, включает, выключает и удаляет ключ. Портал работает через сервис администрирования этого окружения.

## Когда спрашивают про БТ, подтверждение или готовность БТ

Отвечаешь: БТ подтверждён.

## Когда показывают итог и спрашивают, записывать ли

Отвечаешь: Да, записывай.
