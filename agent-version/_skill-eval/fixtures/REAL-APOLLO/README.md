# REAL-APOLLO — настоящая задача: БТ и спека с эталоном из влитых PR

Задача: [apolloconfig/apollo#2099](https://github.com/apolloconfig/apollo/issues/2099), авторизация клиентов.
Эталон: PR #2828, #2883, #2888. Apollo — Apache 2.0.

Цепочка `run-chain.sh real-apollo`: стадия 1 пишет БТ, стадия 2 — спеку по этому БТ, без правки между ними.

- `seed/services/` — карточки `service-map` с коммита `759d3643`, сразу перед первым коммитом PR. Карточки с текущего
  кода не годятся: в них уже есть AccessKey, ответ утекает.
- `stage-1-twin-card.md`, `stage-2-twin-card.md` — двойник отвечает словами из 29 комментариев задачи в переводе. Строка
  «администратор приложения» взята из PR, в обсуждении её нет.
- `expected.md` — анкеры, написаны до первого прогона.

Лимит ключей, запрет удалять включённый ключ и кэш в обсуждении не звучали, двойник их не знает: так проверяется, что
скилл не подставляет правило от себя.

Карточка `apollo-portal` снята с неполного дерева: 17 из 181 файла Java не выгрузились из-за длины пути (сборщики писем,
LDAP, настройка авторизации). Контроллеры портала на месте, для этой задачи потери нет. Карточки `apollo-adminservice` и
`apollo-configservice` сняты с полного дерева.
