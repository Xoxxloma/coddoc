# staff-web — frontend

> Генерируется. Правки руками затираются.
> Заметки человека — в `services/manifest.yaml`, поле `notes`.
> Форма — `reference/card.template.md` скилла `service-map`. Соседние карточки формой не являются.

## Назначение

Рабочее место сотрудника библиотеки: им пользуются на стойке выдачи, в отделе фонда и на регистрации читателей. Библиотекарь сканирует билет и экземпляр, выдаёт и принимает книги, разбирает полку броней; библиотекарь фонда проводит поступления, загружает библиографические записи, собирает перевозки между филиалами, передаёт книги на реставрацию, ведёт инвентаризацию и списание; сотрудник регистрации оформляет, продлевает, блокирует и закрывает читательские билеты и принимает оплату штрафов. Главные объекты на экранах — экземпляры с их статусом в фонде, выдачи, брони на полке, акты фонда, перевозки и читательские билеты.

## Состояние и данные
| Что хранится | Где | Зачем |
|---|---|---|
| выбранный филиал | localStorage | переживает перезагрузку; без него экраны не открываются |
| отсканированный билет на стойке | store в памяти | следующие сканы экземпляров идут на этого читателя до сброса |
| очередь сканов сверки | store в памяти | сканы уходят по одному; при ошибке скан остаётся в очереди с пометкой |
| собираемая перевозка | store в памяти | экземпляры копятся до нажатия «Собрать»; при уходе с экрана теряются |
| ответы сервера | кэш запросов, 30 с | полка броней и должники обновляются при возврате на экран |
| справочник филиалов | кэш запросов, 1 час | не дёргать список на каждом экране |
| черновик новой заявки на билет | sessionStorage | не теряется при случайной перезагрузке вкладки |
| роли и список филиалов сотрудника | из токена входа, в памяти | прячет разделы без роли; сервер права проверяет сам |
| принтер наклеек и отступы листа | localStorage | настраиваются один раз на рабочем месте |
| последний открытый раздел | localStorage | после входа открывается он, а не главная |
