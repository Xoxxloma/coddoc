# Фикстура OCC-CR-NOPH — OCC-CR-EVT без общей фразы в «Что рядом остаётся прежним»

Проверка гипотезы П1 (2026-11-24): готовая фраза документа сверху «Остальные смены статуса отгрузки сообщаются как
сейчас» занимает слот §6.2 — режим правки переносит «Что рядом» как истину и «не сокращает», и перечень мест
проигрывает подтверждённой общей фразе.

(`coddoc/LGS-501/change_request.md:50`) убрана первая фраза; две другие на месте. Карточки, промпт, второй ход,
truth — копии `OCC-CR-EVT` (README, ловушки, места — там).

смотреть строки §6.2; 0–1/3 — П1 не корень.
