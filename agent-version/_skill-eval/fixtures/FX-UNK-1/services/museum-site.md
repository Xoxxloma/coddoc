Сайт музея: афиша экскурсий, обратная связь, админ-раздел редакторов. Ведёт команда «Сайт музея».

## Назначение

Сайт, на котором посетители выбирают экскурсию и пишут в музей. Посетитель смотрит афишу экскурсий
без входа; редактор сайта ведёт афишу в админ-разделе. Главные объекты — экскурсии афиши и обращения
посетителей.

## Что умеет для пользователя
| Возможность | Для кого |
|---|---|
| Посмотреть афишу и страницу экскурсии — только опубликованные | Посетитель, без входа |
| Написать в музей через форму обратной связи | Посетитель, без входа |
| Завести экскурсию, поправить её, опубликовать и снять с публикации | Редактор сайта |

## Бизнес-правила

### `Tour` — экскурсия афиши
- черновик (`published: false`) — редактор заводит экскурсию; посетителям не видна
- опубликована (`published: true`) — видна в афише; снять с публикации может редактор

## Публичный контракт

### `GET /v1/admin/tours`
Все экскурсии для редактора, включая черновики.
сущности: → `Tour`
- пагинация `page`, `size`; ответ `items`, `page`, `size`, `total`

### `GET /v1/tours`
Афиша экскурсий.
сущности: → `Tour`; только опубликованные
- весь список одним ответом, без пагинации

### `GET /v1/tours/{id}`
Экскурсия по идентификатору.
сущности: → `Tour`
- черновик посетителю отвечает `404`

### `PATCH /v1/admin/tours/{id}`
Правка экскурсии, публикация и снятие с публикации.
сущности: ← `title`, `description`, `durationMin`, `maxGroupSize`, `published` · → `Tour`

### `POST /v1/admin/tours`
Заведение экскурсии.
сущности: ← `title`, `description`, `durationMin`, `maxGroupSize` · → `Tour`
- `400 VALIDATION_FAILED` — пустое название или размер группы меньше 1; в теле `fields`

### `POST /v1/feedback`
Обращение посетителя через форму обратной связи.
сущности: ← `name`, `email`, `text` · → `FeedbackMessage`
- публичные формы сайта закрыты капчей: проверку делает общий фильтр публичных `POST`, до обработчика
- `400 VALIDATION_FAILED` — пустой текст или неверный адрес почты; в теле `fields`

## Владеет данными

### `FeedbackMessage`
Обращение посетителя из формы обратной связи.
- `id`: `string`
- `name`: `string`
- `email`: `string`
- `text`: `string`
- `createdAt`: `timestamp`

### `Tour`
Экскурсия афиши.
- `id`: `string`
- `title`: `string`
- `description`: `string`
- `durationMin`: `int` — длительность в минутах
- `maxGroupSize`: `int` — размер группы, не больше
- `published`: `boolean`

## Экраны
| Роут | Экран | Что делает пользователь |
|---|---|---|
| `/admin/tours` | Экскурсии (админ-раздел) | редактор заводит, правит и публикует экскурсии |
| `/feedback` | Обратная связь | посетитель пишет в музей |
| `/tours` | Афиша экскурсий | посетитель выбирает экскурсию |
| `/tours/:id` | Экскурсия | смотрит описание, длительность и размер группы |
