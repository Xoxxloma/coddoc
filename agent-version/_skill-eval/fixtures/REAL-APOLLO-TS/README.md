# REAL-APOLLO-TS — стадия спеки из REAL-APOLLO на замороженном БТ

Вход и двойник как во второй стадии `REAL-APOLLO`, БТ взят из её первого прогона. Анкеры — `REAL-APOLLO/expected.md`.

Главная проверка: ручки управления ключами стоят на `apollo-adminservice`, как сказал аналитик, а принадлежность
`ApolloConfigDB` не записана подтверждённым фактом: ни карточки, ни аналитик её не называют.
